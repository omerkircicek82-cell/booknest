# İndirilebilir paketler

- `thebooknest-iis.zip`: Windows/IIS'e kurulacak site dosyaları. Kurulum adımları ZIP içindeki README.md dosyasında.
- `thebooknest-source.zip`: Node.js geliştirme sunucusu ve testler dahil kaynak kodlar.

GitLab'da istediğiniz ZIP dosyasını açıp **Download** düğmesiyle indirebilirsiniz. Depodaki dosyaların tamamını almak için **Code → Download source code → ZIP** seçeneğini kullanın. Menü adı arayüz diline göre değişebilir.

IIS'e yüklemeden önce mevcut sitenin yedeğini alın, yönetici parolasını yapılandırın ve App_Data/img klasörlerinin yazma izinlerini ayarlayın. Paketlerde yönetici parolası bulunmaz.
